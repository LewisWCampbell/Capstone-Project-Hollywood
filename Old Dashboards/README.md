# HOLLYWOOD Dashboard Bundle

Run locally from this folder:

```bash
streamlit run app.py
```

Included:
- App code: `app.py`, `pages/`, `utils/`, `.streamlit/`
- Core data: `feature_data_longform.csv`, `feature_taxonomy.csv`, `genre_data.csv`
- Dashboard outputs: `movie_clusters_final.csv`, `cluster_summary.csv`, `sub_cluster_summary.csv`
- Latest artifacts: `results/pipeline_artifacts.pkl` (+ run history if present)
- OMDB cache: `omdb_data/omdb_movies.json` (if present)
