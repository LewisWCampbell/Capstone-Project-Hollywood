Project HOLLYWOOD

IDF Pipeline — Per-Type Preprocessing
Step 1 Load Genome Data
Pivot longform genome scores into wide matrix
~8,000 movies × 247 genome features (continuous 0–1)
Step 2 Load OMDB Metadata
Extract year, rating, genre, decade from OMDB JSON + jordan_metadata.csv
Title lookup, tt_codes, decade extraction
Step 3 Genre + Decade One-Hot
Append binary feature columns to the genome matrix
~23 genre columns (genre_Action, genre_Drama, ...) ~10 decade columns (decade_1920s, ..., decade_2020s)
Decades are independent binary signals — no ordinal assumption
Step 4 Per-Type Preprocessing
Each feature type handled according to its nature. Drop constant features across all types.
Genomes (247)
Continuous 0–1
Impute missing → median
Keep as-is
Genres (~23)
Binary 0/1
Fill NaN → 0
No scaling
Decades (~10)
Binary 0/1
Fill NaN → 0
No scaling
Step 5 IDF Weighting
Inverse Document Frequency weights features by rarity across movies.
Transforms: raw score×IDF · sublinear (1+log)×IDF · bm25 saturation curve
Genomes — IDF weighted
Genres — unweighted
Decades — unweighted
SWEEP: 7 configs (raw, sublinear, bm25×5 k1 values)
Step 6 UMAP Dimensionality Reduction
Production: 30D clustering + 3D visualisation · correlation distance · min_dist=0.0
SWEEP: 216 combos (n_components × n_neighbors × metric × min_dist)
Metrics: silhouette, trustworthiness, DBCV
Step 7 HDBSCAN Clustering
Production: min_size=60 · min_samples=15 · eps=0.1 · eom
SWEEP: 350 combos (min_cluster_size × min_samples × epsilon × selection_method)
Metrics: silhouette, DBCV, persistence (ARI), avg membership probability
Step 8 LLM Cluster Naming
Ollama llama3.2:3b names each cluster from its top discriminative features
Centroid-based feature ranking → prompt → concise name
Step 9 Export + Dashboard
Joblib artifact bundle → Streamlit dashboard launch
Labels, embeddings, cluster names, probabilities, feature matrix
